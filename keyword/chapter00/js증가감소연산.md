- JS에서 증가/감소 연산을 하는 여러가지 방법을 조사하여 정리해주세요. 🍠
  - ++변수: 변수를 증가시키고 그 값을 반환한다.
    ```jsx
    let x = 5;
    console.log(++x); // 6
    ```
  - 변수++: 값을 반환한 후 변수를 증가시킨다.
    ```jsx
    let x = 5;
    console.log(x++); // 5
    console.log(x); //6
    ```
  - —변수: 변수를 감소시키고 그 값을 반환한다.
    ```jsx
    let x = 5;
    console.log(--x); // 4
    ```
  - 변수— : 값을 반환한 후 변수를 감소시킨다.
    ```jsx
    let x = 5;
    console.log(x--); // 5
    console.log(x); // 4
    ```
