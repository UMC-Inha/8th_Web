### 호이스팅 (Hoisting) 🍠

<aside>
💡 호이스팅: JavaScript에서 변수와 함수 선언이 코드 실행 전에 메모리에 미리 저장되는 현상

</aside>

```jsx
//함수 선언문
console.log(subtraction(5, 3)); // 2 : 정상 작동

function subtraction(a, b) {
  return a - b;
}
```

```jsx
//함수 표현식
console.log(subtraction2(5, 3)); // 오류 발생

let subtraction2 = function (a, b) {
  return a - b;
};
```

함수 표현식은 변수에 저장되므로 변수는 호이스팅되지만, 초기화는 실행 도중에 이루어진다.

따라서, 호출 시점에서 함수가 아직 정의되지 않았기 때문에 오류가 발생한다.

```jsx
//화살표 함수
console.log(subtraction3(5, 3)); // 오류 발생

let subtraction3 = (a, b) => {
  return a - b;
};
```

화살표도 함수 표현식과 동일하게 동작하기 때문에 오류가 발생한다.
