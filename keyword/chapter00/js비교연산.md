- JS에서 비교 연산을 하는 여러가지 방법을 조사하여 정리해주세요. 🍠
  - == : 값이 같은지 비교할 때 사용
  - === : 값과 타입이 같은지 비교할 때 사용
  - ! = : 값이 다른지 비교할 때 사용
  - ! == : 값과 타입이 다른지 비교할 때 사용
  - > :연산자 앞에 온 값이 더 큰지 비교할 때 사용
  - < :연산자 뒤에 온 값이 더 큰지 비교할 때 사용
  - > = :연산자 앞에 온 값이 뒤에 온 값보다 크거나 같은지 비교할 때 사용
  - < = :연산자 앞에 온 값이 뒤에 온 값보다 작거나 같은지 비교할 때 사용
