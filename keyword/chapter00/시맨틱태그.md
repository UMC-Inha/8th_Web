- div 태그로만 페이지를 구조화 하는 것이 좋은가? 🍠

  그렇지 않다. 남용되면 가독성이 떨어지고 유지보수가 어려워진다.

  따라서 아래와 같이 Header나 nav 같은 태그를 사용한다.

- **`Sementic Tag`**를 잘 활용하였을 때 장점은? 🍠

  - 가독성이 좋고 유지보수가 용이하다.
  - 웹 접근성이 좋다.
  - 각 섹션의 의미가 명확해지기 때문에 페이지의 레이아웃과 디자인을 더 효율적으로 구성할 수 있다.

  - 기타 태그 추가 정리해보기 🍠
    - mark: 강조된 텍스트를 나타날 때 사용하는 태그
    - main: 페이지의 주요 콘텐츠를 나타내는 태그, 일반적으로 한 페이지 당 하나 존재
    - output: 사용자 입력에 대한 결과를 표시하는 태그
