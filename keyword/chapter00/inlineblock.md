### 실습 🍠

- 그러면, **`inline-block`**은 어떠한 방식으로 동작할까요? 🍠
  `inline` element처럼 **한 줄에 나란히 배치**되지만 `block` element처럼 width, height 지정 및 margin, padding 지정이 가능하다.
- **`block`**, **`inline`**, **`inline-block`** 직접 html과 css를 활용해서 무엇이 다른지, **`VS Code Live Server Extension을 활용`**하여, 실습 한 이미지를 첨부하여 설명해주세요. 🍠
  ![image.png](attachment:1fc78dea-8146-4ea6-9aae-9e11ef73aa99:image.png)
  - **`block`**과 **`inline-block`**은 width와 height가 적용 가능하다.
  - `inline`에서 **좌우 margin**은 적용되지만 **상하 margin**은 적용되지 않는다.
