- 타입 스크립트에만 존재하는 타입 🍠

  - any 🍠
    JS로 구현되어 있는 코드에 TS를 적용할 때 사용할 수 있으며 , JS에 존재하는 모든 값을 오류 없이 받아올 수 있다.

    ```tsx
    let state: any;

    state = 123; // 가능
    state = { value: 0 }; //가능
    ```

    **타입 안정성**을 전혀 고려하지 않으므로 예기치 않은 **오류가 발생**할 수 있다!

  - unknown 🍠
    무엇이 할당될지 아직 모르는 상태일 때의 타입을 뜻한다.
    any 타입과 유사하게 **모든 타입의 값이 할당**될 수 있지만, any를 제외한 **다른 타입으로 선언**된 변수에는 unknown 타임 값을 할당할 수 **없다.**

    ```tsx
    const anyVal: any = 1;
    const unknownVal: unknown = "Deogi";

    const a: number = anyVal; //정상
    const b: string = unknownVal; // Error
    ```

    위의 코드 예시에서 anyVal은 any 타입으로 선언되었으므로 어떤 타입의 값도 할당 가능하다.
    unknownVal은 unknown 타입으로 선언되었으므로, 이 값을 다른 타입에 할당하려면 타입을 명시적으로 좁히거나 검사가 필요하다.

    - 타입 검사
      ```tsx
      if (typeof unknownVal === "string") {
        const b: string = unknownVal; // 정상
      }
      ```
    - 타입 단언 ( type assertion )
      ```tsx
      const b: string = unknownVal as string; // 강제로 타입 지정
      ```

  - void 🍠
    아무것도 반환하지 않는 빈 함수 타입이다.
    필수로 void 타입이라고 명시하지 않아도 된다.
  - never 🍠
    함수가 무엇도 반환하지 않는 타입을 나타낸다.
    ⇒ 정상적으로 끝나지 않거나 값을 반환하지 않는 함수
    **사용 예시**

    - 오류를 던지는 함수

      ```tsx
      function throwError(message: string): never {
        throw new Error(message);
      }

      throwError("Error");
      ```

    - 무한 루프

      ```tsx
      function infiniteLoop(): never {
        while (true) {
          console.log("This will never end");
        }
      }

      infiniteLoop();
      ```

      위에서 infiniteLoop() 함수는 무한 반복되고 끝나지 않는다.
