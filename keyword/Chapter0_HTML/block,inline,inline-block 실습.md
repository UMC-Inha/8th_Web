🍠 **display 속성 비교: block, inline, inline-block** 🍠

## 📝 block, inline, inline-block의 특징

### 1️⃣ Block 요소 (`display: block;`)
- 너비, 높이 지정 가능  
- 부모 요소의 최대 너비를 차지(한줄씩 차지)  
- font의 크기는 요소의 크기에 지장이 없음.  
- margin, padding 등의 속성들이 모두 정상 적용  

---

### 2️⃣ Inline 요소 (`display: inline;`)
- 너비, 높이 지정 불가  
- 본인이 차지한 요소공간만큼 너비를 차지(한 줄에 여러개 배치 가능, 줄을 모두 채우고 넘어가는 경향이 있어 짤림현상이 있음)  
- font의 크기에 따라 요소의 크기가 변함.  
- 높이 방향으로 적용되는 속성이 제대로 적용이 안됨.  

---

### 3️⃣ Inline-Block 요소 (`display: inline-block;`)
- 너비, 높이 지정 가능  
- 본인이 차지한 요소 공간만큼 너비 차지, 더 이상 하나의 요소가 줄에 안들어갈 경우 자르지 않고 다음 라인으로 이동  
- font의 크기에 따라 요소의 크기가 변하지 않음  
- 높이 방향으로 적용되는 속성이 정상 적용  


## 해당 특징을 확인할 수 있는 실습 코드 파일은 display.html에 올려두었습니다.
