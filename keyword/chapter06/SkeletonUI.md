- Skeleton UI는 무엇인가요? 🍠
  콘텐츠가 로딩 중일 때 표시되는 가짜(placeholder) UI
  ex) 텍스트나 이미지가 아직 로드되지 않았을 때, 회색 박스나 라인 형태로 자리만 보여주는 방식
- Skeleton UI를 활용했을 때 장점에 대해 정리해주세요 🍠
  - 로딩 체감 시간 단축 효과
    - 실제 로딩 속도가 빨라지는 건 아니지만, 사용자에게는 무언가 진행 중이라는 느낌을 주어 지루함을 줄일 수 있다.
  - UI 일관성 유지
    - 레이아웃이 완전히 바뀌지 않기 때문에 화면이 깜빡이거나 갑작스럽게 변경되는 것을 방지한다.
  - 사용자 이탈 방지
    - 로딩 중 백지 상태보다 Skeleton을 보여줄 경우 사용자 이탈률이 줄어든다.
