- **`useQuery` 는 무엇인가요?** (커스텀 훅과 비교) \*\*\*\*🍠

  ### useQuery

  `useQuery`는 TanStack Query에서 제공하는 **데이터 패칭 전용 훅**으로, 서버에서 데이터를 가져오고 그 상태를 **자동으로 관리**해주는 기능을 제공.
  주로 단일 요청을 처리할 때 사용하며, 다음과 같은 기능이 포함되어 있다.

  - **데이터 캐싱**
  - **로딩/에러/성공 상태 관리**
  - **자동 리패칭 (리페치) 및 재시도**
  - **백그라운드 refetch**
  - **staleTime, cacheTime 설정**

- `useCustomFetch` 커스텀 훅과 비교했을 떄 `useQuery`는 어떤 장점이 있나요? 🍠
  |                         | `useCustomFetch`         | `useQuery`                               |
  | ----------------------- | ------------------------ | ---------------------------------------- |
  | **자동 캐싱**           | 직접 로직 작성해야 함    | 내장 기능 제공                           |
  | **데이터 재사용**       | 매번 요청 발생 가능성 큼 | 동일한 `queryKey` 사용 시 캐시 재사용    |
  | **자동 refetch**        | 직접 구현해야 함         | 포커스, 리마운트 시 자동 재요청 지원     |
  | **에러/로딩 상태 관리** | 개별 state 관리 필요     | 내장 상태 (`isLoading`, `error` 등) 제공 |
  | **복잡한 상태 분기**    | 직접 조건문 작성         | 내장 상태로 코드 간결                    |
  | **개발 툴 연동**        | 불가능 또는 수동 연동    | `ReactQueryDevtools` 지원                |
  | **staleTime/cacheTime** | 직접 구현 필요           | 옵션으로 간단히 설정 가능                |
  | **자동 retry**          | 직접 재시도 로직 작성    | `retry` 옵션으로 손쉽게 설정 가능        |
  커스텀 훅은 로직을 재사용하기에 유용하지만, 데이터 fetching과 관련된 복잡한 상태 관리(캐싱, 리패칭, 에러처리 등)는 `useQuery`가 훨씬 강력하고 안정적으로 제공한다.
